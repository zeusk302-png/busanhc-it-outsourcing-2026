GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다. `.nojekyll`을 사용하며 별도 빌드가 없습니다.

학생 배포 파일만 포함합니다. 강사용 원본 공고, 출처 매핑, 검증용 학생 기록과 로컬 계정·호스팅 설정은 포함하지 않습니다.

이 저장소의 docs는 작업 원본에서 재생성합니다. 원본 프로젝트의 scripts/build-github-pages.py가 공개 범위를 관리합니다.
